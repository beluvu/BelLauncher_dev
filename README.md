# Beluvu Launcher

Лаунчер Minecraft на Python. Интерфейс — HTML/CSS/JS внутри окна WebView2, логика — Python.
Только стандартная библиотека и pywebview.

## Возможности

- Установка и запуск версий Minecraft (Vanilla, Fabric, Quilt, Forge, NeoForge).
- Поиск и установка модов, ресурспаков и шейдеров (Modrinth).
- Сборки (модпаки) из Modrinth: установка, обновление, удаление, изменение своих модов.
- Установки: переключение между сборками и обычными версиями.
- Скины: встроенные, свои PNG и скачивание по нику.
- Автоматическая Java (Adoptium), если на компьютере её нет.

## Друзья и новости

- Ник (3–16 символов, латиница, цифры и `_`), выбирается при первом входе на вкладку «Друзья». Сменить может только администрация.
- Общий чат и личные сообщения, до 300 символов, антиспам 2 секунды.
- Профиль: описание, аватарка (буква, эмодзи или свой NFT-плащ), до 6 NFT-плащей и показ предметов (все или выбранные).
- Новости публикует администрация.

Работает через Supabase (`beluvu/social.py`, миграции в `supabase/migrations`). Ник можно сменить раз в 30 дней. Выключается в `beluvu/config.py`: `SOCIAL_ENABLED = False`.
Без сети остальная часть лаунчера работает как обычно.

## Обновления лаунчера

- Версия в `beluvu/config.py` (`APP_VERSION`). Новую версию публикует администрация во вкладке «Обновления» админки:
  нужен файл `BeluvuLauncher.exe` и прямая https-ссылка на него (например, asset релиза на GitHub).
- Лаунчер проверяет версию при запуске. Если есть новее, внизу бокового меню появляется кнопка «Обновить до X».
- Файл скачивается, проверяется размер и SHA-256 из админки. Если сумма не совпала, обновление отменяется.
- Замена делается батником (`apply_update.bat` в `%APPDATA%\BeluvuLauncher\update`): он ждёт закрытия лаунчера,
  заменяет exe и запускает новый. Работает только в собранном exe; из исходников только проверка версии.

## Сборка .exe (нужна Windows)

1. Установи Python 3.12+ с python.org (галочка «Add to PATH»).
2. Запусти `build.bat`.
3. Готовый файл появится в `dist\BeluvuLauncher.exe`.

Распространяй только `BeluvuLauncher.exe`. Исходный код не публикуется (см. `LICENSE`).

## Пароль и вход на другом ПК

- В «Друзьях» → свой профиль → «Сохранить пароль» (от 6 символов). Пароль хранится в базе хешем.
- На новом компьютере в «Друзьях» → «Уже есть аккаунт?» введите ник и пароль. Лаунчер сохранит ключ аккаунта
  в `%APPDATA%\BeluvuLauncher\account.key`, после чего кошелёк и ник будут те же.
- После 5 неверных попыток вход по нику блокируется на 15 минут.
- Если пароль забыт, админ сбрасывает его кнопкой «Сбросить пароль» в админке; потом игрок задаёт новый в «Друзьях».

## Запуск из исходников (для разработки)

    python -m pip install -r requirements.txt
    python main.py

Тесты (без сети):

    python -m unittest discover -s test -v


## Где лежат данные

Папка лаунчера: `%APPDATA%\BeluvuLauncher` (настройки, Java, логи).
Папка игры: установки и сборки внутри неё. Открывается из Настроек.
